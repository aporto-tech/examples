# Aporto Examples

Example apps and starter projects for Aporto.

Use this repository for small, public, copy-pasteable integrations that help developers
get to a working result quickly.

## Planned Examples

- TypeScript SDK quickstart
- CLI skill runner
- MCP server integration
- Image generation workflow
- Search and LLM workflow
- Webhook/status polling example

## Rule

Examples should be minimal, complete, and safe to publish. Internal routing,
provider configuration, billing logic, and abuse controls belong in the private
core app repository.
